SAVE THIS FOR LATER

Your pocket cheatsheet.

The commands you’ll reach for
again and again.

⌂

Find your way

pwd

Show your current folder.

cd projects

Move into a folder. cd .. goes up.

＋

Make things

mkdir notes

Create a folder.

touch todo.txt

Create an empty file.

⇄

Move things

cp a.txt b.txt

Copy a file.

mv a.txt notes/

Move or rename a file.

⌕

Read & search

cat notes.txt

Print a file’s contents.

grep "hey" notes.txt

Find matching lines.

✎

Edit with vim

vim notes.txt

i insert · Esc normal

:w save · :q quit · :wq save & quit
